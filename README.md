# Dolu Bilişim

Dolu Bilişim'in bireysel ve kurumsal teknoloji hizmetleri için Next.js tabanlı web sitesi.

## Geliştirme

```bash
npm ci
npm run dev
```

## Kontroller

```bash
npm test
npm run build
```

İçerik ve hizmet kataloğu `lib/site-content.mjs` dosyasında tutulur. İletişim adresleri ve telefon bilgileri doğrulanmadan arayüze eklenmeyecektir.
